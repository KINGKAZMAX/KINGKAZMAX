# Profile maintenance

The root README is the personal GitHub profile. The interactive index is `docs/index.html`; GitHub Pages should publish the `main` branch's `/docs` folder. The application and P2P service code at the repository root are existing projects and remain independent.

## Editing

1. Update the short introduction in `README.md` only when the focus changes.
2. Add a selected project only when it has a useful README, clear contribution and source attribution, and a preview or reproducible artifact.
3. Update the corresponding project entry in `docs/index.html` when changing the selected list.
4. Keep private projects, unpublished research, credentials, and local notes out of this repository.
5. Check GitHub light and dark themes, narrow screens, keyboard interaction, and reduced motion after changing visuals.

Topics describe the repository's contents. They are not certifications or endorsements. Research interests should not be rewritten as qualifications without evidence.

## Existing project documentation

The previous root README is preserved in `docs/p2p-llm-os.md`, with its source commit and historical-status notice. This profile update does not verify that project's live services.

## Weekly review

- Check the profile and Pages links.
- Record one meaningful project change with a clear commit message.
- Reply to relevant project issues.
- Replace outdated claims and screenshots.
- Review the 3–6 selected projects quarterly.
