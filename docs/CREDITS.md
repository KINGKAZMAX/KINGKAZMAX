## Privacy and interaction

- The pocket note and preferences use the visitor's browser local storage. Notes are not sent to KINGKAZMAX.
- No analytics, third-party fonts, trackers, or external runtime libraries are added by this interface. GitHub Pages serves the site.
- Sound starts off and only plays after an explicit toggle. Animation can be stopped and respects reduced-motion settings.
- The focus timer uses a deadline while the page remains open; closing or reloading the page resets it.
- Thought cards and generated prompts are creative prompts, not measured research findings or official PTCG game cards.
- GitHub README displays images, GIFs and links. JavaScript interactions run on this GitHub Pages site, not inside GitHub's README.
